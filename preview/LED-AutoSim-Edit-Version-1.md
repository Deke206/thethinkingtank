This branch is isolated for the layered vehicle viewport review. Production/main has not been changed.

The self-contained local review package is stored in Google Drive folder `Edit Version 1 - LED AutoSim` and contains the HTML page, CSS, JavaScript, side rim/window foreground masks, front grille/headlight/valance masks, rear window/plate/valance masks, and the interior top view.

Preview lighting is off by default. LED effects are generated dynamically between the base vehicle and foreground mask layers; no LEDs are baked into the vehicle images.
