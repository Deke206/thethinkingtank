# SIM Auto exact-car prototype

This draft branch uses the approved photorealistic black sedan artwork as the visible vehicle, not a wireframe substitute.

The `sim/ledsimauto.html` route loads the self-contained configurator from verified Base64 text segments. The vehicle artwork is reconstructed from six verified WebP segments so the GitHub connector can preserve the binary asset without altering it.

## Working interactions

- underglow
- rocker-board lighting
- wheel rings
- wheel-well lighting
- headlight accents
- color selection
- brightness control
- solid, breathe, chase, and spectrum effects
- six-step guided flow
- full-build animation
- live summary and planning estimate
- saved session state
- contact-page handoff

The lighting artwork and clickable areas share the same 975 × 450 SVG coordinate system as the approved sedan stage, keeping the visible lighting aligned with the vehicle.
