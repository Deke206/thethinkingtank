## Standard normalized zones

- `.page` / `.page--<page>` — page root
- `.site-nav` — primary navigation
- `.page-hero` — hero or banner
- `.page-main` — main content
- `.page-section` / `.page-section--<name>` — editable content section
- `.zone--left`, `.zone--center`, `.zone--right`, `.zone--top`, `.zone--bottom` — positional edit zones
- `.action-trigger` — interactive control
- `.form-object` / `.form-control-object` — forms and controls
- `.media-object` — image, video, canvas, or SVG
- `.site-footer` — footer
